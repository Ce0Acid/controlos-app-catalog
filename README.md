# ControlOS App Catalog

Public pure-data test catalog maintained by Ce0Acid. Minecraft mod sources, binaries, worlds and credentials are not published here.

Hello World1.0.0 was validated by the production ControlOS AppDocument-v1 parser and closed RepositoryCatalog-v1 parser. It has no device sources or actions. SHA256 is content integrity, not a publisher signature.

GitHub Pages source: main /docs. Catalog endpoint: https://ce0acid.github.io/controlos-app-catalog/catalog-v1.json

In-game use requires server administrator approval of this HTTPS source and separate computer CONFIGURE authority. No community submissions are currently accepted.
