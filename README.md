# ControlOS App Catalog

Public pure-data test catalog maintained by Ce0Acid. Minecraft mod sources, binaries, worlds and credentials are not published here.

Hello World1.0.0 was validated by the production ControlOS AppDocument-v1 parser and closed RepositoryCatalog-v1 parser. It has no device sources or actions. SHA256 is content integrity, not a publisher signature.

GitHub Pages source: main /docs. Catalog endpoint: https://ce0acid.github.io/controlos-app-catalog/catalog-v1.json

In-game use requires server administrator approval of this HTTPS source and separate computer CONFIGURE authority. No community submissions are currently accepted.

## Optional world profile

Hello World 1.0.0 now has a separate immutable passive P35 world profile, generated with the original ControlOS WorldLayoutDocument writer and validated with the production P35 parser. Minimum display: 1 by 1 Minecraft blocks. No device sources or actions. The original 1.0.0 and 1.1.0 application payloads are unchanged. Profile download and physical display assignment require separate explicit authorized steps. Hashes provide content integrity, not publisher signatures.

World Door Demo 1.0.0 is a pure-data integration test for an interactive 3 by 2 block panel. It uses only the existing public Vanilla door OPEN/CLOSE actions. It contains no world coordinates, device identities or bindings. An authorized player must explicitly link their own door at the target panel. Downloading it grants no device rights.
